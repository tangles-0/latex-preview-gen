# Agentic continuity

1. Read the web implementation and testing skills in this directory.
2. Keep secrets server-side and authenticate every Latex/worker callback.
3. Validate inputs, use Drizzle queries, and add durable schema changes.
4. Treat process restarts and duplicate requests as normal worker conditions.
5. Escalate requirements that weaken authentication, validation, tests, or
   serialized access to non-concurrent services.
6. Verify tests, types, lint, and a production build before completion.
